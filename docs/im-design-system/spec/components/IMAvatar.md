# IMAvatar

A person: photo when there is one, else a two-letter Hebrew monogram on `accent-soft`.

## Props
- `size` — `sm` 32 · `md` 42 (default) · `lg` 56.
- `artist` — `1…8`: adds a ring in that artist's identity colour. Customers never get a ring.
- `src`, `name` — the monogram is derived from `name`.

## Replaces
`Avatar*`, `.avatar-native`.
