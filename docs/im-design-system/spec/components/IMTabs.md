# IMTabs

Switch between views of the same data, in place. `IMTabs`, `IMTabsList`, `IMTabsTrigger` (optional `icon`, optional `count`), `IMTabsContent`.

A `surface-2` rail (`radius-control`) with 38px triggers (`radius-inset`); the active one lifts to `card` with `shadow-raised` and weight 800. Up to five triggers; more becomes a select or a filter.

## Replaces
`Tabs*`.
