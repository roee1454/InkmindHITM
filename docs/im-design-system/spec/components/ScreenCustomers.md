# ScreenCustomers

A whole screen assembled only from IM parts — the customers list as it should look after the migration. Names and numbers are examples.

Page head (`IMHeadline` + `body-sm` muted with tabular counts) · primary action at the inline end · `IMSearchInput` + icon-only filter `IMButton` · `IMTabs` with counts · a flush `IMCard` of `IMListRow`s (`IMAvatar`, `IMSubtitle`, caption, `IMStatusLabel`, `chevron-end`) · `IMPagination`.
