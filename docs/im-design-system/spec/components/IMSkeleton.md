# IMSkeleton

The loading state: grey `surface-2` blocks that keep the exact shape of the content they stand in for.

## Rules
- Every data view has one. Never "טוען…" as plain text, never a spinner in place of a list.
- Mirror the real layout (avatar circle, two text lines, trailing meta) so nothing jumps when data lands.
- Pulse is disabled under `prefers-reduced-motion`.

## Replaces
`Skeleton`, and the `טוען…` strings in features.
