# IMSearchInput

A search field with a leading filled `search` icon and a clear button once it has a value. Debounced; the parent receives the settled value.

## Props
- `variant` — `default` (on a page) · `subtle` (inside a toolbar or popover, no shadow).
- `size` — `md` (default) · `sm` (inside pickers and menus).

## Replaces
`SearchInput`, `getSearchInputClasses`.
